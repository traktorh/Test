# Состав ССО — сайт игрового сообщества

Сайт с личными кабинетами, званиями, тематическими испытаниями и памяткой перед игровой сессией. История на сайте относится к игровому сообществу и не описывает реальное подразделение.

## Запуск локально

```powershell
python -m http.server 3000
```

Открой `http://localhost:3000`.

## Деплой

- **Vercel:** подключи репозиторий без дополнительных настроек.
- **Netlify:** команда сборки `node build.js`, папка публикации `dist` (настройки указаны в `netlify.toml`).

## Аккаунты администраторов

При первом запуске можно использовать один из встроенных аккаунтов:

- admin / admin123
- moderator / moderator123
- leader / leader123

## Как устроены звания и испытания

- Новый аккаунт получает статус **Кандидат**. Администратор назначает ему первое звание — **Рядовой**.
- Лестница включает 15 званий: от **Рядового** до **Полковника**. Повышения требуют баллов; для некоторых этапов нужны итоговая проверка или решение руководителя.
- Всего в системе 22 ситуационных испытания: от 3 до 5 вопросов в каждом. Начиная со звания **Старший сержант**, как минимум один тест каждого звания содержит не менее пяти вопросов.
- Шесть званий от Младшего сержанта до Майора имеют по два разных теста: Младший сержант, Сержант, Прапорщик, Младший лейтенант, Лейтенант и Майор.
- В кабинете показываются только тесты текущего звания; после выдачи нового звания прежние тесты пропадают. Если у звания два испытания, нужно пройти оба, чтобы получить повышение.
- Правильный ответ приносит 10 баллов. При повторном прохождении учитывается только улучшение результата. После повышения баллы и результаты испытаний текущего звания сбрасываются.
- Продвижение проверяется по баллам текущего звания, активному выговору и, где указано, итоговому тесту или решению руководителя.
- Отметки памятки перед игровой сессией и запрос на ручное повышение сохраняются в аккаунте.
- Администратор может назначать звания, отмечать итоговую проверку и выдавать или снимать выговор.

## Хранение данных

Это статический сайт без сервера: аккаунты и прогресс находятся в `localStorage` конкретного браузера и не синхронизируются между устройствами. Поэтому сохранённый запрос на повышение виден администратору только в том же браузере. Не используй встроенные пароли на публичном сайте и не вводи здесь реальные или чувствительные данные.

При первом входе после обновления система автоматически перенесёт прежнее звание на новую шкалу, но сбросит старые баллы и результаты тестов: содержание испытаний изменено.
