# Состав — сайт клана

Сайт на Node.js с общей SQLite-базой, аккаунтами, званиями, тематическими тестами и панелью администратора.

## Запуск

Нужен Node.js 22.13 или новее. В папке проекта выполни:

```powershell
npm start
```

Открой `http://localhost:3000`. При первом запуске сервер напечатает одноразовый ключ настройки. Введи его на стартовой странице и используй временные данные администратора:

```text
Ник: ClanBoss
Пароль: ClanStart2026!
```

После входа сайт **обязательно попросит сменить временный пароль** и не даст открыть панель управления, пока новый пароль не сохранён. Смена пароля завершит все остальные сеансы администратора. Не продолжай использовать временный пароль. Форма настройки доступна только один раз; другие участники не могут получить роль администратора. База создаётся в `data\clan.sqlite`; не удаляй и не публикуй её.

Для проверки логики тестов и званий:

```powershell
npm test
```

Для отдельной базы или нестандартного порта можно задать `DATABASE_PATH` и `PORT` перед запуском. Для первого production-запуска обязательно задай `ADMIN_SETUP_KEY` длиной не менее 20 символов.

## Как устроены роли и повышение

- Новые участники создают аккаунт по нику и паролю и автоматически получают звание **Шпана**. На этом звании тесты закрыты.
- Только первый аккаунт после чистого запуска получает административные права. Он начинает с временным паролем `ClanStart2026!`, который нужно обязательно сменить при первом входе. Старые сеансы аннулируются при смене пароля. Панель управления и её кнопки видны только администратору; остальные аккаунты нельзя сделать администраторами через интерфейс.
- Администратор ищет участника по нику и назначает звание. После назначения звания **Фраер** открывается первый тест; последующие звания открывают новые тематические тесты.
- За каждый тест можно заработать до 40 баллов. При повторном прохождении учитывается только улучшение результата. После повышения баллы и результаты тестов текущего этапа сбрасываются.
- После начального звания у каждого следующего ранга свой тест из четырёх ситуационных вопросов и оригинальная иллюстрация-задание (11 наборов); варианты ответов меняют положение правильного варианта и проверяют выбор, а не угадывание по позиции.
- Пороговые значения и специальные условия соответствуют таблице званий на изображении. Для перехода к **Бойцу** администратор отмечает сдачу стрельбы; активный выговор блокирует повышение.
- Переходы **Шнырь → Блатной** и **Положенец → Смотрящий** требуют ручного утверждения администратора. Переход **Шпана → Фраер** также назначается администратором после проверки знания Устава.
- В панели администратора звание назначается вручную по нику, баллы при этом сбрасываются. Администратор также отмечает стрельбу и выдаёт или снимает выговор (0 дней — снять).

## Для размещения в интернете

Запускай сайт за HTTPS reverse proxy и установи `NODE_ENV=production`, чтобы session-cookie использовал флаг `Secure`. Храни папку `data` на постоянном диске и регулярно делай её резервную копию. Всем участникам нужен доступ к одному и тому же запущенному серверу и базе данных.
