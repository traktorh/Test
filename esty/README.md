# Состав — сайт клана

Сайт с аккаунтами, званиями, тематическими тестами и панелью администратора. Работает без бэкенда — данные в localStorage.

## Запуск локально

```powershell
python -m http.server 3000
```

Открой `http://localhost:3000`.

## Деплой на Vercel

Просто подключи репозиторий к Vercel. Никаких настроек не нужно.

## Деплой на Netlify

Подключи репозиторий к Netlify и оставь настройки сборки из `netlify.toml`: команда `node build.js`, папка публикации `dist`. Сборка копирует в неё только файлы сайта и изображения.

## Аккаунты администраторов

При первом запуске используй один из этих аккаунтов:

- admin / admin123
- moderator / moderator123
- leader / leader123

## Особенности

- Данные хранятся в localStorage браузера
- Каждый пользователь имеет свои данные (не общие для всех)
- Нет серверной части — работает на любом статическом хостинге

## Как устроены роли и повышение

- Новые участники создают аккаунт по нику и паролю и автоматически получают звание **Шпана**. На этом звании тесты закрыты.
- Администратор ищет участника по нику и назначает звание. После назначения звания **Фраер** открывается первый тест; последующие звания открывают новые тематические тесты.
- За каждый тест можно заработать до 40 баллов. При повторном прохождении учитывается только улучшение результата. После повышения баллы и результаты тестов текущего этапа сбрасываются.
- После начального звания у каждого следующего ранга свой тест из четырёх ситуационных вопросов и оригинальная иллюстрация-задание (11 наборов).
- Пороговые значения и специальные условия соответствуют таблице званий. Для перехода к **Бойцу** администратор отмечает сдачу стрельбы; активный выговор блокирует повышение.
- Переходы **Шнырь → Блатной** и **Положенец → Смотрящий** требуют ручного утверждения администратора. Переход **Шпана → Фраер** также назначается администратором.
- В панели администратора звание назначается вручную по нику, баллы при этом сбрасываются. Администратор также отмечает стрельбу и выдаёт или снимает выговор (0 дней — снять).
